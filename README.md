# THE ORACLE
### An Interactive Alternate Reality Explorer

> *"Reality is only one of the possibilities."*

**THE ORACLE** is an interactive, speculative fiction exploration instrument engineered with the atmosphere of an enigmatic scientific artifact from an alternate civilization. It enables users to submit hypothetical inquiries and explore intricately generated, logically grounded parallel universes without requiring external APIs or paid services.

---

## Architecture & Features

### 1. The Observatory (Landing Portal)
* **Central Inquiry Matrix**: Full-screen atmospheric opening experience with glowing amber accents and Cormorant Garamond typography.
* **Infinite Hypothetical Randomization**: Dynamic randomization of over 60 curated questions with an animated dice actuator and pool-shuffling mechanics.
* **Vernier Calibration Dials**: Physical-feeling sliders allowing fine-tuning of Temporal Anchor (*Ancient, Industrial, Contemporary, Deep Future*), Entropy Drift (*Subtle, Moderate, Rupture*), and Civilization Vector (*Technocratic, Ecological, Consciousness, Equilibrium*).

### 2. Autonomous Local Reality Engine
Generates complete, intelligent alternate narratives across six structured axioms:
* **The Divergence**: The departure event that severed historical continuity.
* **The New World**: Evolution of architecture, culture, governance, and daily customs.
* **Systemic Cascades**: Three unexpected second-order consequences.
* **The Human Element**: Ground-level lived experiences of ordinary citizens.
* **The Paradox**: Philosophical implications and existential contradictions.
* **The Future Horizon**: Long-range vector and chronological epoch projection.

### 3. Interactive Multiverse Exploration
* **Deep Axiom Expansion ("Go Deeper")**: Unlocks second-order historical consequences and micro-narrative layers.
* **Localized Branching ("What if this changed?")**: Binds new hypothetical twists onto existing timelines with causal continuity.
* **Chronological Epoch Tree**: Interactive vertical timeline with clickable events that fork realities from specific historical dates.
* **The Prime Comparison Chronograph**: Side-by-side dual-reality spectrometer contrasting the alternate strand against consensus reality (Earth-0).
* **Decryption Reading Mode (Hotkey: `T`)**: Fullscreen, distraction-free reading flow with keyboard navigation (`Spacebar`, arrow keys) and cipher decryption transitions.
* **Telemetric Dossier Export**: Generates and downloads high-resolution 1200×800 archival specimen cards (.PNG) or formatted text dossiers.

### 4. The Multiverse Archive & Constellation Star Chart
* **Chronological Log**: Searchable, editable, persistent repository stored locally in the browser.
* **The Transdimensional Constellation**: Real-time canvas star chart visualizing realities as glowing stellar nodes and gravitational filament links.

### 5. The Resonance Field (Procedural Audio)
* **Web Audio Synthesis**: Native real-time ambient drone synthesizer blending detuned sub-bass sine waves (54 Hz & 55.2 Hz binaural beating), celestial shimmers (162 Hz LFO breathing), and cosmic pink noise.
* **Tactile Haptic Acoustics**: Delicate mechanical clicks on dial turns, engage sweeps on generation, and chimes on branch creation.

### 6. The Uncharted (Experimental Chamber)
* **The Impossible Question**: Generates radical philosophical thought-experiments with instant universe exploration.
* **Reality Collision**: Forces two saved universes from the archive to intersect, calculating emergent paradoxes and hybrid laws.
* **The Unknown**: Ambient revelator of short, enigmatic aphorisms regarding existence and consciousness.

## Technical Stack

* **Framework**: React 19 + TypeScript
* **Build System**: Vite
* **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
* **Motion & Physics**: Framer Motion
* **Iconography**: Lucide React
* **Sound Engine**: Native Web Audio API
* **Persistence**: LocalStorage API

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript type check
npx tsc -p tsconfig.app.json --noEmit

# Build production bundle
npm run build
```
